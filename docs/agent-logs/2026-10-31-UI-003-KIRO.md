## Technical decisions
- Three.js 0.187.0 is isolated behind dynamic `import('three')` inside one client leaf. Server/static components remain unchanged.
- Geometry and textures are generated at runtime from deterministic local code. There are no downloaded models, textures, fonts, shaders or production bundles.
- Desktop/mobile scene density differs: 10,500/5,200 sculpture points, 3,200/1,500 crown points, 1,800/700 grass instances and 220/90 debris points.
- Device pixel ratio is capped at 1.5 desktop and 1.15 compact viewports.
- The render loop pauses offscreen and while the document is hidden; it stops on context loss and unmount. Reduced motion renders one still frame.
- Reference comparison prompted two iterations: lower/smaller rock horizon, foreground-only near grass, darker terrain, reduced glow and a separate raised particle crown.

## SEO / accessibility / performance changes
- The particle world is decorative and `aria-hidden`; H1, description, CTA and all page content remain exported HTML.
- Dynamic Three.js import confines the 3D library to the client scene chunk.
- Instancing is used for grass; shared materials/geometries limit draw and allocation overhead.
- Resize/visibility/intersection/context listeners and all geometry/material/texture resources are cleaned up.
- Reduced-motion users receive one still frame; CSS fallback covers no-JS/WebGL failure.
- Mobile scene density and DPR are reduced to lower GPU cost.

## Known issues, risks and rollback
- This is a clean-room recreation of visible behavior, not the source site's exact proprietary model or shader. The central form is an original particle sculpture with a similar silhouette.
- Three.js increases client JavaScript compared with UI-002; Lighthouse and real-device GPU profiling are still required.
- npm reported 16 moderate dependency-tree vulnerabilities. No automatic `audit fix --force` was run because it could introduce breaking dependency changes.
- Business content and contact assumptions from SITE-001 remain unchanged.
- Rollback UI-003 by restoring the UI-002 versions of `CinematicScene.tsx`, its module CSS, HeroSection and hero CSS, then removing `three` and `@types/three`.
